# Jemimah Osei

My personal site: https://jemimahosei.com

A static site with no build step. Open `index.html`, or run `npm start` and visit http://localhost:8000.

- `index.html`, `style.css`, `script.js`: the page, its styles and its small script
- `assets/img`: screenshots and posters, all WebP
- `assets/media`: demo videos (MP4) with English captions (VTT)
- `files`: the downloadable CV

The previous version of the site is kept on the `original-site` branch.

The demo videos and screenshots were recorded from the projects with demo data.
